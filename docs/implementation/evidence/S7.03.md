# S7.03 Evidence — ABM entity and guidance state machine

- Moved `EntitySurfaceToAirMissile` and `ItemSurfaceToAirMissile` with `git mv` into `icbm.classic.content.abm`, renaming them to `EntityAntiBallisticMissile` and `ItemAntiBallisticMissile`. The entity and item registry IDs remain `anti_ballistic_missile`; client render/model identifiers were not changed.
- Removed `SAMTargetData` and `ConfigSAMMissile`. The ABM stores its target UUID and implements `IRadioTargetAssignable`; `ConfigMissile.TIER_2_HEALTH` is retained. Remaining flight-speed consumers use `ConfigAbm.FLIGHT_SPEED` (4.0 default); ABM guidance's BOOST/GUIDE/REACQUIRE/self-destruct settings are local constants at this stage because S7.09 completes user-facing ABM configuration.
- `AbmGuidance.tick` executes on the server before `EntityMissile.tick`. The base `EntityProjectile.tick` still performs ray tracing, collision handling, and movement through `updateMotion`. The ABM override clears any legacy launcher flight logic and calls `super.updateMotion()` for that movement path; `decreaseMotion` is overridden to avoid generic drag/gravity modifying guidance-commanded velocity. This prevents the previous flight logic from overwriting ABM velocity while retaining projectile movement/collision.
- Implemented BOOST (vertical launch velocity), GUIDE (intercept math, bounded rotation and target-velocity acceleration), REACQUIRE (nearest radar-classified threat every 10 ticks, 30-block search radius and 40-tick timeout), and SELF_DESTRUCT (`ExplosionInteraction.NONE`, then discard). Guidance state, state age, fuel and target UUID are persisted with `abm_state`, `ticks_in_state`, `fuel_left`, and `target_id` keys.
- `TileRadarStation.isThreat` excludes ABMs; the existing missile threat/explosive checks remain. Updated entity/item registration, missile-stack construction, launcher speed selection, EMP compatibility, incoming-message documentation, renderer comment, and the prior SAM registration test.
- Added `AbmGuidanceGameTest` for targetless timeout/no terrain damage and bounded steering toward a stationary target.

- Verification: `export JAVA_HOME=/usr/lib/jvm/java-25-openjdk && ./gradlew build` completed successfully, including GameTests. `grep -rln "SurfaceToAirMissile\\|SAMTargetData\\|ConfigSAMMissile" src/` returned no matches.
