补充结论（字节码核对，非签名）：`ValueOutput` **没有** `lookup()`（只有 `ValueInput` 有），因此 `SaveNodeItemStack`
不单独取 `HolderLookup.Provider`；`TagValueOutput#store(String, Codec, T)` 的字节码为
`codec.encodeStart(this.ops, value)`，`ops` 由 `createWithContext(..., provider)` 构造，`ItemStack.OPTIONAL_CODEC`
/ `BlockState.CODEC` 等注册表相关 Codec 直接可用。`Direction.CODEC` 的类型是
`StringRepresentable$EnumCodec<Direction>`（`extends StringRepresentableCodec` → `Codec`），可作 `store`/`read` 的
`Codec<T>` 实参，无需改存名称字符串。

## 与步骤卡的差异

- **`nodeFacing` → `nodeDirection`**：步骤卡/porting-guide §4 只列出 `nodeVec3`、`nodeIdentifier` 等新方法名，未列
  `nodeFacing`；节点类按本次要求改名 `SaveNodeDirection`，故构建方法同步改为 `nodeDirection`（与 `nodeVec3d→nodeVec3`、
  `nodeResourceLocation→nodeIdentifier` 同一处理）。
- **`nodeWorldDim` 签名**：按本次澄清改为 `Function<E, Level>` + `BiConsumer<E, Identifier>`（1.12 为
  `Function<SaveObject, World>` + `BiConsumer<SaveObject, World>`）；保存 `level.dimension().identifier()`，读回把
  `Identifier` 交给 setter，javadoc 已写明由调用方 `server.getLevel(ResourceKey)` 解析。
- **`nodeINBTSerializable` → `nodeSavable` 保留两个重载**：1.12 的 4 参重载（`save, load, builder`，`lib/projectile/EntityProjectile`
  的 `InGroundData` 在用）一并移植为 `nodeSavable(name, save, load, builder)`。1 参重载按本次要求用 `in.childOrEmpty(key)`；
  4 参重载改用 `in.child(key)`（`Optional`），以保留 1.12“键缺失时不重建对象”的语义（否则会用 builder 造一个空对象覆盖原值）。
- **`SaveHandler` 的 CompoundTag 入口**：1.12 的 `save(E)`/`load(E, NBTTagCompound)` 按干净切换替换为
  `saveToTag(E, HolderLookup.Provider)`/`loadFromTag(E, CompoundTag, HolderLookup.Provider)`，未保留旧签名别名；
  构建器 API（`mainRoot()`/`addRoot(...)`/`.base()`/`parent()`/`disableSave()`）不变。
- **`IBuilderRegistry` 默认方法**：新增 `save(Part, ValueOutput)`（键 `"id"` + 可选 `"data"` 子节点，空 `data` 用
  `discard` 删除以复现 1.12“无附加数据则不写 data”）与 `load(ValueInput.ValueInputList, C)`；1.12 的
  `save(Collection<Part>)`（返回 `NBTTagList`）删除，列表保存改由 `SaveBuildableObjectList` 用 `out.childrenList(name)` 逐元素调
  `save(Part, ValueOutput)`。
- **Lombok `@Getter` 改显式方法**：`BuildableObject`/`BuildableObjectRegistry` 在本机 JDK 25 + Lombok 1.18.48 下
  `@Getter` 不生成方法（`javap` 直接试验证），改为手写 `getRegistryKey()/getRegistry()/getSaveHandler()/isLocked()`
  （行为与 1.12  Lombok 生成的 getter 一致；`isLocked` 字段由 `isLocked` 改名为 `locked` 避免 Lombok `isXxx` 命名歧义）。
  注：Gradle 增量/全量构建中既有 lombok 文件（config/util/**）仍正常，非本步引入。
- **`javax.annotation.Nonnull/Nullable` → `org.jspecify.annotations`**：本机 classpath 无 JSR-305，改用仓库既有约定
  `org.jspecify.annotations.NonNull/Nullable`（见 S1.02 的 `RegistryLookup`）。
- **`NBTConstants` 未改动**：步骤卡“改动文件”列含 `lib/NBTConstants.java`，但 S1.01 已就绪、本步无新键名，故不动。
- **`src/gametest/resources/fabric.mod.json` 追加入口**：Fabric gametest API 只扫描 `fabric-gametest` 入口点类，
  不注册则新测试类不参与 `runGameTest`（实测：注册前 2 tests、注册后 6 tests）。
- **`SaveNodeItemStack` 不需要 `lookup()`**：`ValueOutput` 无 `lookup()`（`ValueInput` 有），`store` 自带 `createWithContext`
  给的 ops，故直接用 `ItemStack.OPTIONAL_CODEC`；保存仍跳过空栈（与 1.12 一致）。
- **枚举未知值**：`SaveNodeEnum.load` 捕获 accessor 异常并 `ICBMClassic.logger().warn`，保留调用方当前值（不调用 setter）。
