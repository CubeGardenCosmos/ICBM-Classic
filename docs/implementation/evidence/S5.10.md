## 结果

- 完成判据：五个回归场景均执行，Fabric GameTest 数从基线 143 增加至 148，`fabric-gametest` entrypoint 包含 `icbm.classic.test.regression.P1RegressionGameTests`。
- `AllBlocksPlaceable`：遍历 `icbmclassic` namespace 的注册方块；每个方块断言实际状态等于其 default state 且方块存在。每个 `EntityBlock` 断言 `newBlockEntity` 工厂返回非空实体。
- `AllItemsStackable`：检查 136 个命名空间物品的 `ItemStack` 非空、hover name 非空，并逐条核对合并语言资源的名称键。`LangGameTest.mergedEnglishCoversTheContent` 已独立验证所有方块/物品语言键及 41/136 注册数；本场景保留语言键断言以满足 stack/name 测试闭环，并新增堆栈与 hover-name 断言。
- `AllEntityTypesSpawnable`：创建、加入 level、确认 level 按 UUID 返回同一实体，再在 `finally` 中 discard；执行日志报告 17 个类型。
- `AllExplosivesTrigger`：完整遍历 ExplosiveRegistry 的 25 项。已有明确 effect assertions 的 22 项不重复触发：
  - `BasicBlastsGameTest`：常规 TNT、breaching、sonic、incendiary、shrapnel、anvil、fragmentation、repulsive、attractive、exothermic、endothermic、antigravitational、mutation 的方块/实体效果。
  - `GasBlastsGameTest`：chemical、debilitation、smoke 的毒效/效果/烟雾实体。
  - `ThreadedBlastsGameTest`：nuclear、thermobaric、antimatter 的方块破坏效果。
  - `EmpBlastsGameTest`：EMP 对 Creeper、掉落物、容器物品、primed explosive 与配置方块替换的效果。
  - `EnderBlastGameTest.enderBlastTeleportsEntitiesToCustomizationTarget`：ender 传送效果。
  - `RadioactiveGameTest.rotBlastSpreadsRadioactiveBlocks`：rot 的放射性方块替换效果。
  剩余 `colors`、`contagious`、`redmatter` 在本场景中触发并断言颜色粒子调色板初始化、附近僵尸获得气体效果、红物质实体生成。红物质 `DEFAULT_SIZE/MAX_SIZE` 暂设为 `MIN_SIZE` 并在 `finally` 恢复；实体在测试结束前 discard。扫描中断言覆盖计数 22、未覆盖触发计数 3，以便未来新增定义不会静默漏测。
- `LaunchToRadarScenario`：复用 `LauncherGameTest` 发射网络、`RadarStationGameTest` 来袭检测、`EmpTowerGameTest` 已充能塔与概率处理方式；发射 condensed missile，真实雷达检测后经同频道 RadioRegistry 消息送达 EMP 塔并断言导弹已被处理。`REQUIRES_POWER`、EMP 导弹击杀/燃料概率配置均由 `try/finally` 还原。
- 未修改或删除已有测试；`AllExplosivesTrigger` 将现有有效果断言的爆炸留给既有测试，避免重复异步爆炸影响其他 GameTest。

## 与步骤卡的差异

- `LangGameTest` 已覆盖全部翻译键与注册数量，因此新 item 场景在这些键上有意重复断言，但另行增加题卡要求的 stack 非空和 hover name 检查。
- 对 `EntityBlock`，本场景核对 block entity 工厂可创建实体；单块回归所用的低层 `helper.setBlock` 没有在 radar_station 等类型上稳定产生 live block entity。机器实际放置/实体行为由 `LauncherGameTest`、`CruiseLauncherGameTest`、`RadarStationGameTest`、`EmpTowerGameTest` 等已有场景验证。
- 爆炸遍历中的 22 项使用上述已有测试作为“已有覆盖”并跳过二次触发；其余三项由本场景补测。没有实现 S5.11 或之后步骤。
- 完整构建实测 1:11.06，未达到 10 分钟，无需拆 batch；javap 结果还确认 Fabric 的 `GameTest` 注解没有 `batch()` 成员。
