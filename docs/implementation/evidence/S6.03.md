
`EMP_TOWER` and `EMP_TOWER_FAKE` share the same registered block. A pair of `registerForBlockEntity` calls would conflict in Fabric's block-keyed provider map, so one `registerForBlocks` provider dispatches to the main tile's exposed storage or fake tile's host storage without duplicate provider registration. The other four machine types use `registerForBlockEntity`.

## 改动文件

- `src/main/java/icbm/classic/lib/energy/EnergyApi.java`: 注册 launcher base、cruise launcher、launcher screen、radar station；共享 EMP 方块 provider 同时解析 EMP 主 tile/fake tile；frame/connector 在对应 launcher network 含 base 或 cruise launcher 时提供 `LauncherNetworkEnergy`，否则返回 `null`。
- `src/main/java/icbm/classic/lib/energy/LauncherNetworkEnergy.java`: 对网络内 base 与 cruise launcher 进行同事务平均分配，保留旧算法 `remaining / remainingNodes + 1` 防零分配；只插入，汇总存量/容量。
- 删除 `src/main/java/icbm/classic/content/blocks/launcher/network/NetworkEnergyStorage.java`，并从 `LauncherNetwork` 移除旧存储成员及 getter。
- 新增 `src/gametest/java/icbm/classic/test/energy/LauncherNetworkEnergyGameTest.java` 并在 `src/gametest/resources/fabric.mod.json` 登记。
