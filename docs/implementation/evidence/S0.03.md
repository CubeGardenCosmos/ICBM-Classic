## 与步骤卡的差异

1. 步骤卡写 `mkdir -p run/server && echo eula=true > run/server/eula.txt`。实测 Loom 1.18.3 的 `runServer` 运行目录是 `run/`（EULA 必须放 `run/eula.txt`）；`run/server/` 未被使用，已删除。`/run` 原本就在 `.gitignore` 中。
2. `build.gradle` 骨架中的 `clientCompileOnly`、`clientAnnotationProcessor` 配置名在 Loom 1.18.3 拆分源集下**存在**（`./gradlew dependencies --configuration ...` 解析成功），无需改名。
3. `runServer` 冒烟结束时 Gradle 报 `BUILD FAILED ... exit value 143`（SIGTERM）：原因见上，非模组问题；步骤卡未要求任务退出码为 0，完成判据只要求日志出现两行。
4. 步骤卡操作 9 说“用任意 16×16 或更大的导弹物品纹理复制”，实际使用 `textures/items/missiles/missile_module.png`（16×16 RGB，无 alpha）。
5. 两个 mixins JSON 的 `"compatibilityLevel": "JAVA_25"` 被 Mixin 0.8.7 接受：专用服务端启动日志无兼容性相关告警（`grep -iE "compatibility|Unsupported" .dev/tmp/s003-server.log` 无输出），未回退 `JAVA_21`。
