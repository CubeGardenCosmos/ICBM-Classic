## 目标 / 操作

新增纯 Java `icbm.classic.lib.energy.EnergyFormat`：`format(long)` 提供 FE、k、M、G 格式（最多一位小数），`formatWithCapacity(long,long)` 以逗号分隔并显示存量/容量精确值。新增 client-only `EnergyBar`，作为可复用 GUI component 在悬停时显示 `icbmclassic.energy.stored` 提示。

五个机器菜单（`ContainerLaunchBase`、`ContainerCruiseLauncher`、`ContainerLaunchScreen`、`ContainerRadarStation`、`ContainerEMPTower`）均注册四个 `ContainerData` 数据槽。`ContainerBase.addEnergyData` 在服务端读取当前 `IcbmEnergyBuffer` 存量与容量，按索引 0/1 = 存量低/高 32 位、2/3 = 容量低/高 32 位同步；客户端在 `ContainerBase` 中合并接收的 int，screen 每帧从菜单读取同步后的 long 值，未访问客户端方块实体的未同步能量字段。

能量条放在五个 GUI 面板的本地坐标 `(141, 66)`，位于电池槽下方，不改动任何槽位布局。新增 `icbmclassic.energy.stored` 与 `icbmclassic.energy.unit` 英文翻译，并以 JUnit 覆盖 0、999、1000、12500、1,000,000、2,500,000,000 FE 与存量/容量组合。
