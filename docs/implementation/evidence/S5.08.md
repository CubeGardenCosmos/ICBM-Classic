- build：满足，`All 141 required tests passed :)` 与 `BUILD SUCCESSFUL`。
- runDatagen：满足，成功；534 项，0 变更文件。
- 账本：六件物品及其数据组件替代项均已按 S5.08 归档；GPS capability 实现 DROPPED，替代为 `icbmclassic:gps_data` 数据组件。

## 与步骤卡的差异

- `ItemDefuser` 不再继承被 S5.01 判定 DROPPED 的 `ItemICBMElectrical`；改为普通 `Item`，省略已删除基类提供的电力接口，拆除行为由 Fabric `AttackEntityCallback` 接入。
- 电池按卡仅注册为普通可用物品，不显示伪造能量值/能量条；机器能量槽临时过滤器现在匹配真实 `icbmclassic:battery`，S6.04 再由 Team Reborn `SimpleEnergyItem` 实现能量，并按 S6.04 卡迁移到 `icbm.classic.lib.energy.item.ItemBattery`。
- GPS capability 类按要求 DROPPED，GPS 行为统一落在 `gps_data` 组件中；坐标监听兼容入口从旧 capability 改为组件读写。
- 火箭筒 target trace 使用 26.3 已核验的 `Level.clip(ClipContext)`，取实体碰撞盒、忽略流体；激光器/雷达枪使用 26.3 `Entity.pick(double,float,boolean)`。

## 未覆盖 / 已知限制

- 未进行图形客户端手动使用/渲染检查（设备无图形测试能力）；该步骤的服务端逻辑由 GameTest 覆盖。
- 电池的充能、放电与能量显示有意留给 S6.04。
