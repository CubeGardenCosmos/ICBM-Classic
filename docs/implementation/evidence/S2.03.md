## 与步骤卡的差异

1. **`BlockConcrete` 类不新建**：步骤卡写「一个 `Block` 类即可（原版 `Block`），三个实例」，故直接注册三个原版 `Block` 实例，
   旧类记 `MERGED → ModBlocks`。
2. **方块物品放 `ModItems`**：overview §5 明确 `ModItems` 含方块物品（1.12 亦然），故 `RegHelper.blockItem` 调用在 `ModItems#register`。
3. **尖刺伤害源用原版 cactus**：registry-ids.md §7 的伤害类型清单没有 spikes，步骤卡也建议 `damageSources().cactus()`。
4. **玻璃压力板用 `BlockSetType.OAK`**：1.12 是 `Sensitivity.EVERYTHING`（掉落物也能触发），26.3 把这一属性放进 `BlockSetType`，
   木质系才是 EVERYTHING（石质系是 MOBS）。代价：板子的“踩下/弹起”反馈音在 26.3 是木质音效（1.12 所有压力板都用石质音效），
   触发频率与行为不变；玻璃的破坏/踩踏音由 `Properties.sound(SoundType.GLASS)` 保持。
5. **玻璃按钮不再覆写点击音**：1.12 覆写为 `BLOCK_STONE_BUTTON_CLICK_ON/OFF`，`BlockSetType.STONE` 本身就是这两个音效，等价。
6. 只设了硬度、1.12 未显式设抗性的方块（尖刺、玻璃按钮）用 26.3 的 `strength(h)`（抗性 = 硬度）；1.12 显式设了抗性的
   （加固玻璃 48、压力板 1）用 `strength(h, r)`。
7. `MapColor`：1.12 `Block(Material)` 会取材质的地图色，故混凝土用 `MapColor.STONE`、尖刺用 `MapColor.METAL`
   （26.3 无 `MapColor.IRON`，METAL 是其改名）；玻璃系不设（默认 NONE）。
