### 症状与诊断

根因是测试夹具的弹道不稳定，不是雷达分类算法或扫描频率错误。`src/main/java/icbm/classic/content/blocks/radarstation/TileRadarStation.java:212-215` 只把 `ticksInAir > 1` 的实体分类为威胁；`src/main/java/icbm/classic/lib/projectile/EntityProjectile.java:628-657` 默认给投射物施加重力，测试原本在 `RadarStationGameTest.java:74-75` 只赋予水平速度，未关闭重力。实体会落入测试结构地面；投射物离开/解除方块嵌入时 `EntityProjectile.java:327-357` 将 `ticksInAir` 重置为 0。失败状态同时表明实体仍被雷达 map 跟踪、缓冲尚有 8,000 能量，但有效飞行 tick 已归零，因此雷达按设计不把它列为来袭目标。它离地碰撞后的速度/脱离过程还会用 `level.getRandom()`（`EntityProjectile.java:348-357`），令该测试的观测时机依赖随机物理结果。

另一个已修复的 suite 隔离问题是 `src/gametest/java/icbm/classic/test/radar/RadarRegistryGameTest.java` 原先在四个场景中调用 `RadarRegistry.clear(level.dimension())`（旧行 66、84、102、121）。这会清空共享 GameTest level 中所有测试实体的整张雷达地图，而不是只清理本场景实体；完整套件日志确认多个约 50 项的 batch 在同一 GameTest server 内运行。现已删去这些维度级清空，保留各场景对自身实体的 `RadarRegistry.remove`/`discard` 清理。相邻机器测试曾临时改写 `ConfigMain.REQUIRES_POWER`（例如 `EmpTowerGameTest.java:22-53`、`LauncherGameTest.java:47-54`），故雷达测试也不再依赖该共享全局值。

### 相关行为对照与修复

- 旧版 `legacy-1.12/src/main/java/icbm/classic/content/blocks/radarstation/TileRadarStation.java:147-171,232-240` 与移植版 `TileRadarStation.java:149-160,207-216,236-242` 都是在有电时扫描、仅在导弹飞行 tick 大于 1 后按下一位置距离是否缩短分类，并在扫描同一 tick 广播。生产实现保留旧有分类语义，未改生产代码。
- `ConfigRadar.SCAN_TICKS` 默认值为 1（`src/main/java/icbm/classic/config/machines/ConfigRadar.java:18-20`）；`RadarMap.UPDATE_DELAY=20`（`src/main/java/icbm/classic/lib/radar/RadarMap.java:23-27,52-56`）是 map 维护周期，不是雷达扫描周期。扫描间隔不是本次失败的根因。

- 电力判断读取 `ConfigMain.REQUIRES_POWER`（`src/main/java/icbm/classic/lib/energy/EnergyRules.java:11-22`；默认值 true 见 `src/main/java/icbm/classic/config/ConfigMain.java:12-16`）。旧测试在设置 `false` 后只于成功回调恢复（旧 `RadarStationGameTest.java:57-58,78-86`）；现在直接设置该雷达的满缓冲并且完全不写这个全局配置。
- `maxTicks=10` 有明确 tick 预算：投射物经过 2 个飞行 tick 后满足 `ticksInAir > 1`，`SCAN_TICKS=1` 保证至多再等一个雷达 tick；扫描当 tick 会同步调用 `RadioRegistry.popMessage`（`TileRadarStation.java:152-160`）。预留启动/实体与方块实体 tick 顺序，10 tick 仍保守；初始水平间距 8.5 格、速度 0.4 格/tick，理想直线约 21 个 tick 才会越过雷达，因此预算内一直保持“接近”方向。断言仍要求来袭分类、红石灯亮、收到 `IncomingMissileMessage` 且消息指向该实体。

## 再发：雷达 GameTest 飞行夹具碰撞（2026-10-15）

### 复现与根因
