## 移植与改动要点

1. **`EntityExplosiveMissile`**：
   - 继承 `EntityMissile<EntityExplosiveMissile>` 并实现 `IExplosive`（委托给 `explosive = new CapabilityExplosiveEntity(this)`）。
   - 持有 `targetRangeDet = new TargetRangeDet(this)`，在 `tick()` 中先调用 `targetRangeDet.update()` 再调用 `super.tick()`。
   - `getMaxHealth()` 根据 `explosive.getExplosiveData().getTier()` 匹配 `ConfigMissile.TIER_*_HEALTH`；构造函数调用 `initHealth(getMaxHealth())`。
   - `onDestroyedBy(DamageSource, float)`：当来源是爆炸或火焰（`DamageTypeTags.IS_EXPLOSION` / `IS_FIRE`）时，调用 `explosive.doExplosion(getX(), getY(), getZ(), new ActionSource(...))`。
   - `interact(Player, InteractionHand, Vec3)`：通过 `ICBMClassicAPI.EX_MISSILE_REGISTRY.onInteraction(this, player, hand)` 拦截玩家右键交互，为真则返回 `InteractionResult.SUCCESS`。
   - `actionOnImpact(HitResult)`：调用 `explosive.doExplosion(...)` 后调用 `super.actionOnImpact(impactLocation)`。
   - `toStack()`：返回 `explosive.toStack()`，若为空则回退到对应爆炸物平铺导弹物品。
   - 存档：通过 `SaveHandler` 保存/加载 `explosive` 节点。

2. **`EntityMissileActionable`**：
   - 继承 `EntityMissile<EntityMissileActionable>`。
   - 持有 `PotentialAction mainAction` 与 `ActionFieldProvider`（提供 `IMPACTED`、`HOST_ENTITY`、`HOST_POSITION`、`TARGET_POSITION`）。
   - 持有 `originalStack`；`toStack()` 返回 `originalStack`（若空回退 `MISSILE_MODULE`）。
   - `tick()` 中调用 `mainAction.update(this.tickCount, !this.level().isClientSide())`，服务端执行 `mainAction.doAction(...)`。
   - `onDestroyedBy` 与 `actionOnImpact` 均经 `mainAction.doAction(...)` 处理。
   - 存档：通过 `SaveHandler` 保存/加载 `potential_action` 与 `original_stack`。

3. **`TargetRangeDet`**：
   - 移植自 1.12：在服务端若设置了 `BallisticTargetingData.impactHeightOffset` 或集束导弹近炸偏移（10 格），当与目标水平平面与空间距离达到阈值时提前触发 `explosive.doExplosion(...)` 并 `discard()`。

4. **`CapabilityMissileStack`**：
   - 新建并实现 `ICapabilityMissileStack`。
   - `getMissileId()` 返回 `ICBMConstants.PREFIX + "missile[" + regKey + "]"`。
   - `newMissile(Level)` 生成 `EntityExplosiveMissile`，赋值 `stack` 并刷新生命值。

5. **`ItemMissile`**：
   - 继承 `ExplosiveFormItem`，单组容量 `MAX_STACK_SIZE = 1`。
   - `appendHoverText` 调用 `appendExplosiveTier(tooltip)` 展示等阶，并调用 `explosive.collectInformation` 收集自定义数据提示。

6. **注册与 Lookup**：
   - `ModEntities`：注册 `EXPLOSIVE_MISSILE`（追踪 32 区块 / 间隔 1 tick）与 `GENERIC_MISSILE`。
   - `EntityMissile` 实现 `IEMPReceiver`，两个实体类型均注册 `IcbmLookups.EMP_RECEIVER_ENTITY.registerSelf` 与 `IcbmLookups.MISSILE.registerSelf`。
   - `ModItems`：`registerFormItems` 中 MISSILE 形态使用 `ItemMissile`；注册 `IcbmLookups.MISSILE_STACK.registerForItems((stack, ctx) -> new CapabilityMissileStack(stack), EXPLOSIVE_MISSILES.values().toArray(new Item[0]))`。
   - `ExMissileContentReg`：`getDeviceStack` 返回 `ModItems.EXPLOSIVE_MISSILES.get(regName)`；落地发射/更新/交互监听器管理与触发。
   - `ExplosiveInit`：落地 `enderMissileCoordSet`，从玩家手持物品读取 `ModDataComponents.GPS_DATA` 并写入导弹爆炸物的 `ExplosiveSettings`，发送 `toolTargetSet` / `noTargetInTool` 消息。
   - `CapabilityEmpMissile`：回填 `EntityExplosiveMissile` 与 `EntityMissileActionable` 的 EMP 触发分支，移除 TODO(S4.02)。
   - `ICBMLanguageProvider`：`ENTITY_NAMES` 加入 `explosive_missile`（Explosive Missile）与 `generic_missile`（Generic Missile）。

7. **GameTest**：
   - 新增 `MissileFlightGameTest`（4 条用例）：
     1. `missileItemIsMissileLookup`：断言 `ICBMClassicHelpers.isMissile` 对导弹物品返回 true、对钢锭返回 false；断言 `CapabilityMissileStack` 产出的实体是 `EntityExplosiveMissile` 且携带 `condensed`。
     2. `condensedMissileFliesArcAndDestroysTargetStone`：测试区生成 `condensed` 导弹，设 `BasicTargetData` + `ArcFlightLogic`，发射后在 400 tick 内通过 `succeedWhen` 断言目标点石头方块被炸成空气。
     3. `explosiveMissileSurvivesSaveRoundTrip`：断言 `EntityExplosiveMissile` 的爆炸物与生命值经 `SaveHandler` 往返一致。
     4. `actionableMissileSurvivesSaveRoundTrip`：断言 `EntityMissileActionable` 的 `originalStack` 经 `SaveHandler` 往返一致。

## 与步骤卡的差异

- **`interact` 签名**：26.3 `Entity#interact` 为 3 参 `(Player, InteractionHand, Vec3)`，按 26.3 签名覆写。
- **Lookup 注册时机**：`MISSILE_STACK` 在 `ModItems#register` 创建完 23 个平铺物品后批量注册；`EMP_RECEIVER_ENTITY` / `MISSILE` 在 `ModEntities#register` 实体类型构建完成后调用 `registerSelf` 注册。
- **GameTest 结构高度与轨迹参数**：测试用例采用起点 `(1, 1, 1)` 到目标 `(5, 1, 1)`（水平距离 4，最大弧线高度约 y=5，飞行耗时 8 tick），完全置于测试结构与屏障内部，避免了 S4.01 中长距离弧线爬升触碰顶部 barrier 的随机阻尼干扰，执行稳定。
