## 与步骤卡的差异

1. **标签页顺序按 1.12 `ICBMCreativeTab#init` 实际顺序**：机器 → 基础方块（混凝土/加固玻璃/尖刺）→ 工具 → 导弹 → 手雷 →
   炸药方块 → 矿车 → 其余（空子弹药、降落伞、气球、玻璃按钮/压力板、粉末、材料）。步骤卡摘要写作「机器→工具→导弹→手雷→矿车→炸药方块→材料」，
   缺少基础方块的位置且矿车/炸药方块顺序与 1.12 相反，故以 1.12 源码为准（步骤卡第 3 条也要求「顺序照抄 1.12」）。
   子弹药放在矿车之后（1.12 的 `explosive_bomblet` 属「其余」段）。
2. **玻璃按钮/压力板放进本模组标签页**：1.12 把它们设在原版红石标签页（`BlockGlassPressurePlate` 用 `CreativeTabs.REDSTONE`，按钮沿用原版默认）。
   26.3 的原版标签页内容由数据驱动，为不让物品在创造模式里消失，改为列在本标签页末尾（已记录）。
3. **`BuiltInRegistries.ITEM` 是 `DefaultedRegistry`**：`getValue(未知 id)` 返回 air 而不是 null，导致 `new ItemStack(AIR)`（count 0）
   触发标签页构建的 `Stack size must be exactly 1`。`RegHelper.item(String)` 改为先 `containsKey` 再取值并返回 null。
4. 占位类名与步骤卡一致（`ExplosiveBlock`、`ExplosiveFormItem`）；1.12 的 `BlockExplosive`/`ItemMissile` 等真实类仍由 S3.09/S4.02/S4.05/S4.06 完成，
   构造签名按步骤卡保持 `(Identifier, Properties)`（物品额外带 `ExplosiveForm`）。
