## 与步骤卡的差异

- 步骤卡第 4 条“带物品的组件类型 javap 查 `ItemStackTemplate`”：26.3 的 `ModDataComponents.HELD_ITEM` 已由 S2.01 定为 `DataComponentType<ItemStack>`（`ItemStack.OPTIONAL_CODEC`/`OPTIONAL_STREAM_CODEC`），本步沿用，未改类型。
- 步骤卡第 5 条“配方 JSON 用 datagen 或手写”：本步采用手写 `src/main/resources/data/icbmclassic/recipe/*.json`（序列化器为无字段的 unit codec，datagen 无收益）。
- `RecipeSerializer` 在 26.3 是 `Record(MapCodec, StreamCodec)`（javap 见上），5 个配方均无字段，故用 `MapCodec.unit` + `StreamCodec.unit`。
- `LangGameTest` 的注册物品数断言 118 → 122：本步新增 4 个独立物品（`cluster_missile`、`held_item_missile`、`parachute`、`balloon`），子弹药为 BOMBLET 形态替换占位而非新增，故为 +4。
