## 与步骤卡的差异

1. **解毒剂清除清单是显式的**：1.12 `onItemUseFinish` 调 `clearActivePotions()`，即清除**全部**效果。步骤卡要求
   「本步先清除原版 `POISON`、`WITHER` …，ICBM 自有效果加 `TODO(S3.05)`」，且 S3.05 卡写明「`ItemAntidote` 清除本步注册的效果」，
   故按卡片实现为清单（POISON、WITHER + `TODO(S3.05)`）。差异如实记录：26.3 版**不会**清除增益效果，1.12 会。
2. **`ItemBattery`、工具、导弹/手雷物品等不在本步**（S5.08/S6/S4）。
3. **`prefab/item/ItemBase`、`ItemICBMBase` 删除**（步骤卡允许「改为普通 Item 子类或删除」）：
   `ItemICBMBase` 只做 `setCreativeTab`/`setName`（26.3 由 `Item.Properties` + `ModItems` 承担）；
   `ItemBase` 的 `.info` 提示文本框架未迁移，因为 shift 检测（`Screen.hasShiftDown`）属客户端类，26.3 拆分源集后不能放进 main 源集，
   正确做法是 client 源集的 `ItemTooltipCallback`（属 S8 文本工作）。**未覆盖**：物品描述提示（1.12 `en_US.lang` 中有 71 个 `.info` 键）
   目前不会显示，已在账本与本文件记录，供协调者决定落到哪一步。
4. `OreDictionary`（`dustSulfur`/`dustSaltpeter`/`ingotSteel`…）→ 物品标签，在 S2.07；配方开关 → `S2.08` 的 `fabric:load_conditions`。
5. 1.12 `ItemCrafting.getStack(name, count)` 里 `if (index > 0)` 的越界 bug 随类一起删除（无调用点）。
