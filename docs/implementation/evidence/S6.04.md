# S6.04 电池与电池槽放电

- 状态：DONE
- 日期：2026-10-15
- 执行者：S604
- 提交：见最终提交
- 环境：WSL2 Linux x86_64；Java 25；Gradle 9.8.1

## 目标

注册 `icbmclassic:battery` 电池，使用 Team Reborn Energy 的堆叠能量组件存储最多 1,000,000 FE，并为五种机器提供从独立电池槽向内部缓冲放电的行为。

## 操作

- `BatteryItem` 位于 `icbm.classic.lib.energy`，实现 Energy 5.0.0 中实际存在的 `SimpleEnergyItem`；容量 `1_000_000`、最大输入 `10_000`、最大输出 `1_000_000`。通过 `EnergyStorage.ITEM` 注册，存量使用其 `ENERGY_COMPONENT`，未自建组件。
- Energy 5.0.0 jar 中不存在用户任务文字提到的 `team.reborn.energy.api.RebornPoweredItem`（javap 报 `class not found`）；接口 javap 显示其可用等效项为 `team.reborn.energy.api.base.SimpleEnergyItem`，故按实际 API 实现。
- 电池槽采用现有每机专用 inventory 槽：发射台基座和巡航发射器为槽 1；发射屏、雷达站、EMP 塔为槽 0。五个菜单已包含这些电池槽，并在现有 GUI 槽位 `(141,47)`（基座/巡航器另有导弹槽 `(88,47)`）；保留原有布局。槽过滤仍限制为注册电池。
- 各机器 server tick 通过自身 `tickPower()` 委托给 `EnergyItemSlotHelper`。helper 检查 `REQUIRES_POWER`、缓冲余量与 `receive` 上限，再以 `ContainerStorage` 单槽上下文从 `EnergyStorage.ITEM` 事务抽取，成功后更新缓冲并提交。
- 新增 `BatteryDischargeGameTest`，且在 GameTest mod 的 `fabric-gametest` entrypoint 注册。测试覆盖关闭电力要求时不放电、开启后机器缓冲增加、电池能量减少及两者总量守恒。

- 新测试 `icbmclassic-test:battery_discharge_game_test_battery_discharges_into_machine_only_when_power_is_required` 已包含在 GameTest mod 配置；151 个必需 GameTests 全部通过。

## 证据 / 结果

- `BatteryDischargeGameTest` 放置 `launcher_base`，预充电池 5,000 FE，断言 `REQUIRES_POWER=false` 时 buffer 与电池不变；开启后断言 buffer 增加、电池电量减少，且 buffer + 电池总量仍为 5,000 FE。
- 日志显示 `151 tests are now running`，最终 `All 151 required tests passed :)`。
- 受限 API 导入仅出现在 `icbm.classic.lib.energy`；机器 tile / menu / screen 不导入 Team Reborn。
