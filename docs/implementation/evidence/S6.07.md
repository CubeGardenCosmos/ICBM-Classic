## 目标与操作

新增 `EnergyInteropGameTest`，在 `fabric.mod.json` 注册。测试将 `REQUIRES_POWER` 设为 true，并放置发射台基座：

1. 使用 `EnergyStorage.SIDED.find(level, pos, Direction.UP)` 获取非空外部存储。
2. 在已提交的 `Transaction` 中插入 500 FE，并断言机器缓冲恰好增加 500 FE。
3. 断言外部存储 `extract(500, transaction)` 返回 0。
4. 创建含 5,000 FE 的 `ModItems.BATTERY`，放入机器电池槽并调用 `tickPower()`；断言机器能量增加、电池能量减少，且外部注入与电池放电后的总能量为 5,500 FE。测试后恢复电力开关与容量配置。
