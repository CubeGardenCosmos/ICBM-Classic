## 移植与改动要点

1. **`EntitySurfaceToAirMissile`**：
   - 继承 `EntityMissile<EntitySurfaceToAirMissile>`，实现 `IRadioTargetAssignable`。
   - 实现 `assignTarget(Entity)` 转发给 `scanLogic.setCurrentTarget(entity)`，供 `IncomingMissileMessage` / 雷达站网络调用。
   - 构造器初始化：生命值设为 `ConfigMissile.TIER_2_HEALTH`；`getMissileCapability().setTargetData(scanLogic)`。
   - `tick()`：服务端先 `scanLogic.tick()` 寻找目标；当存在目标且退出当前飞行逻辑安全（`canSafelyExitLogic()`）时切换为 `FollowTargetLogic(ConfigMissile.SAM_MISSILE.FUEL)`；在距离目标 $\le$ `ConfigMissile.SAM_MISSILE.FLIGHT_SPEED` 时对目标执行 `hurtServer`（伤害源 `ModDamageTypes.source(level, ModDamageTypes.MISSILE_IMPACT, this, null)`，伤害量 `ConfigMissile.SAM_MISSILE.ATTACK_DAMAGE` 为 100），随后 `discard()`。
   - `toStack()`：返回 `ModItems.ANTI_BALLISTIC_MISSILE`（客户端带单例缓存）。

2. **`SAMTargetData`**：
   - 继承 `BuildableObject<SAMTargetData, IBuilderRegistry<IMissileTarget>>`，实现 `IMissileTarget`。
   - 注册 ID 为 `ICBMConstants.id("anti.missile")`。
   - 目标队列最多容纳 5 个目标；扫描周期 10 tick。
   - 扫描实现：根据 `ConfigMissile.SAM_MISSILE.RADAR_MAP_ONLY` 选择 `seekByRadar()` 或 `seekByAABB()`。
   - 26.3 映射：`getEntitiesWithinAABB` 改为 `level.getEntitiesOfClass(EntityMissile.class, targetArea(), this::isValid)`；AABB 构造为 `new AABB(minX, minY, minZ, maxX, maxY, maxZ)`；距离计算使用 `host.distanceToSqr(entity)`；目标过滤排除 `EntitySurfaceToAirMissile` 自身并确保目标存活（`entity.isAlive()`）。

3. **`ItemSurfaceToAirMissile` 与 `CapabilitySAMStack`**：
   - `ItemSurfaceToAirMissile` 继承 26.3 普通 `Item`，`stacksTo(1)`。
   - `CapabilitySAMStack` 实现 `ICapabilityMissileStack`，`getMissileId()` 返回 `icbmclassic:missile.sam`，`newMissile(Level)` 返回 `new EntitySurfaceToAirMissile(ModEntities.MISSILE_SAM, world).getMissileCapability()`。
   - 在 `ModItems#register` 中绑定 `IcbmLookups.MISSILE_STACK.registerForItems((stack, ctx) -> new CapabilitySAMStack(), ANTI_BALLISTIC_MISSILE)`。

4. **注册与资源**：
   - `ModEntities`：注册 `MISSILE_SAM = registerEntity(ICBMEntities.MISSILE_SAM, 0.5F, 0.5F, 32, 1, EntitySurfaceToAirMissile::new)`；注册 `IcbmLookups.EMP_RECEIVER_ENTITY.registerSelf` 与 `IcbmLookups.MISSILE.registerSelf`；清理 `TODO(S4.04)` 注释。
   - `ModItems`：注册 `ANTI_BALLISTIC_MISSILE`（ID `anti_ballistic_missile`）；创造模式物品栏由 `ModCreativeTabs` 接受；模型映射在 `ICBMModelProvider` 中指定 1.12 3D 模型 `item/missiles/surface_to_air`（纹理路径更新为 26.3 `item/missiles/*`）；通过 datagen 自动生成 `anti_ballistic_missile.json` 物品模型定义。
   - `ICBMLanguageProvider`：`NAMES` 与 `ENTITY_NAMES` 增加 `anti_ballistic_missile` 对应英文名 "Anti-Ballistic Missile"。
   - `IncomingMissileMessage`：注释更新为已由 `EntitySurfaceToAirMissile` 落地。

5. **GameTest `SamInterceptorGameTest`**：
   - `antiBallisticMissileRegistration`：断言 `BuiltInRegistries.ENTITY_TYPE` 注册键为 `icbmclassic:anti_ballistic_missile`，物品注册键匹配，`ICBMClassicHelpers.isMissile` 为真，`IcbmLookups.MISSILE_STACK` 正确解析为 `icbmclassic:missile.sam` 且能生成 `EntitySurfaceToAirMissile`。
   - `samScanLogicAcquiresTarget`：断言 `SAMTargetData` 能在 AABB 范围内正确发现并锁定目标导弹实体。
   - `samProximityImpactDestroysTarget`：断言当 SAM 处于近炸距离时，`sam.tick()` 正确对目标造成致死伤害且 SAM 自行 discard。
   - `samInterceptsAndDestroysTargetMissile`：生成匀速直线飞行的 `condensed` 目标导弹（`DirectFlightLogic`），发射 SAM 并通过 `assignTarget` 跟踪，在 200 tick 内通过 `succeedWhen` 断言目标导弹被击毁（`!targetMissile.isAlive()`）。
